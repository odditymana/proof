# テスト画像

PROOF の動作確認のために、このリポジトリ用に自作した画像です。他人の著作物は含みません。

ライセンスは [CC0 1.0](LICENSE)（パブリックドメイン）です。元の HTML（`sources/`）も含め、自由に使えます。

`sources/` にある HTML を、ヘッドレスの Chrome で同じ大きさのスクリーンショットとして書き出して作りました。

```sh
# 例：silver-landscape.png（透明な背景の画像は --default-background-color=00000000 を付ける）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars \
  --force-device-scale-factor=1 --window-size=1414,1000 \
  --screenshot=silver-landscape.png sources/silver-landscape.html
```

## 各画像と、確かめるときの目安

面積の割合は図形の大きさから計算した値です。色の抽出では、縮小や境目のにじみのため少しずれます。

### silver-landscape.png（1414×1000px、白銀比の横長）

| 部分 | 色 | 面積 |
|---|---|---|
| 背景 | `#E8E2D6` | 48.6% |
| 左の帯（幅586px） | `#1F3A5F` | 41.4% |
| 円（直径360px） | `#D9482B` | 7.2% |
| 横長の帯（480×80px） | `#F2C14E` | 2.7% |

- 縦横比は 1:1.414、近い比率は白銀比
- 左の帯の右端は、白銀比の線（左端から41.4%）と重なる

### silver-portrait.png（1000×1414px、白銀比の縦長）

| 部分 | 色 | 面積 |
|---|---|---|
| 背景 | `#F4F1EA` | 47.2% |
| 下の帯（高さ586px） | `#2F5D50` | 41.4% |
| 正方形（400×400px） | `#C43D5A` | 11.3% |

- 縦横比は 1:1.414（縦長）、近い比率は白銀比
- 下の帯の上端は、白銀比・片側・下の線（下端から41.4%）と重なる

### transparent-circle.png（800×800px、透明な背景）

| 部分 | 色 | 不透明な部分に占める割合 |
|---|---|---|
| 円（直径600px） | `#2A6F97` | 85.9% |
| 正方形（200×200px） | `#F4A259` | 14.1% |

- 円の外側は透明（画像全体の55.8%）。色の抽出では集計から外れる
- 見分けられる色が少ないので、色数を5以上にしても指定より少ない色数で止まる

### golden-landscape.png（1618×1000px、黄金比の横長）

| 部分 | 色 | 面積 |
|---|---|---|
| 背景 | `#EFE8DC` | 37.5% |
| 左の正方形（1000×1000px） | `#3A5A78` | 61.8% |
| 円（直径120px） | `#E07A2E` | 0.7% |

- 縦横比は 1:1.618、近い比率は黄金比
- 左の正方形は、黄金螺旋（左下から）の最初の正方形と重なる
- 円の中心（左端から1171px・上端から724px）は、黄金螺旋（左下から）の中心（左端から72.4%・上端から72.4%）と重なる

### gray-tones.png（1414×1000px、ほぼ白黒の写真を想定）

| 部分 | 色 | 面積 |
|---|---|---|
| 地 | `#6E6E6E` | 36.1% |
| 左半分（横方向のグラデーション） | `#1E1E1E` → `#DCDCDC` | 50.0% |
